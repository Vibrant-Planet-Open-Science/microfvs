# Security

Please report security problems privately, not in a public issue. Use GitHub's [private vulnerability reporting](https://github.com/Vibrant-Planet-Open-Science/microfvs/security/advisories/new) for this repo.

Include what you found, how to reproduce it, and the MicroFVS version or image tag. You'll get a reply within a few days. Fixes ship in the next release, and you'll be credited unless you'd rather not be.
